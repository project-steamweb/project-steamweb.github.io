Steam Data Explorer

Steam Atlas
蒸汽图鉴

查询 Steam 游戏资料、全球 16 个区服的本地定价，以及玩家的公开档案与隐私状态。 中文界面，深色响应式设计，零第三方依赖。

AI
本项目由 AI 编写

代码、页面、样式与文档均由 AI（DeepSeek 驱动的编码助手）根据需求生成并迭代完成，人工仅提出需求与反馈。 使用或二次开发前请自行 Review 代码。

Store

游戏资料

简介、截图、宣传片、成就、DLC、发售版本、配置要求、年龄分级与版权信息。

Pricing

全球 16 区价格

一次读取各区本地定价，按公开汇率估算人民币并横向排序，标注非本地货币计价。

Profile

玩家档案

支持 SteamID64、个性域名与主页链接，展示等级、徽章、游戏库、封禁与最近游玩。

Privacy

隐私逐项标注

游戏库、时长、地区、最近在线等逐项标明公开 / 仅好友 / 私密，不把限制伪装成无数据。

这个页面只是仓库首页

完整功能需要 Node.js 后端：Steam 商店与社区接口不返回 CORS 头，且 Web API Key 只能在服务端使用， 因此 GitHub Pages 无法运行本站的 API 代理。 

# 克隆后本地运行（需要 Node.js 20+）
git clone https://github.com/project-steamweb/project-steamweb.github.io.git
cd project-steamweb.github.io
node server.mjs
# 然后访问 http://127.0.0.1:8787
  • 本地运行：最简单，仅自己使用。
  • Node 托管平台：Render / Railway / Fly.io / VPS 运行 node server.mjs。
  • 前后端分离：后端部署到上述平台，前端静态托管到 Pages。
